# Qrious Curators — Creative Studio Website

A premium, high-performance landing page designed for **Qrious Curators**. This project showcases a modern digital studio's capabilities through fluid typography, immersive animations, and a "Vanilla-first" technical approach.

## ✨ Key Features
*   **Custom pointerOrb Interactivity:** A bespoke cursor experience that reacts to interactive elements.
*   **Fluid Responsive Design:** Fully optimized for mobile, tablet, and ultra-wide desktops using CSS Grid.
*   **Performance Focused:** Zero frameworks. Zero libraries. Built for maximum speed and SEO optimization.
*   **Scroll-Driven Storytelling:** Intersection Observer animations reveal content as the user explores the page.

## 🛠️ Technical Stack
*   **HTML5:** Semantic architecture.
*   **CSS3:** Custom properties (variables), Grid, and Flexbox for layout.
*   **JavaScript (ES6+):** Native DOM manipulation for the custom orb logic and scroll observers.

## 🚀 Usage
Simply open `index.html` in any modern web browser to view the experience.
